# PASSIT

Personal digital possession manager (Flutter + Supabase). App sources live under [`passit/`](passit/).

## Quick start

1. Install [Flutter](https://docs.flutter.dev/get-started/install) (stable).
2. Copy [`passit/.env.example`](passit/.env.example) and pass the values at build/run time with `--dart-define` (see [`passit/README.md`](passit/README.md)).
3. From `passit/`: `flutter pub get`, `flutter run`.

Database migrations for Supabase are in [`supabase/migrations/`](supabase/migrations/).
